# 주식왕 다운로드

[웹에서 시작하기](https://skim72.github.io/stockking-downloads/app/) · [주식왕 소개·다운로드 페이지](https://skim72.github.io/stockking-downloads/) · [APK와 변경 내역](https://github.com/SKIM72/stockking-downloads/releases)

주식왕은 가상 자산으로 시세·주문·기업 투자·은행·시즌 순위를 즐기는 웹·Android 주식 게임입니다. 같은 계정으로 로그인하면 서버에 저장된 잔액·보유 주식·주문을 함께 이용합니다. 로그인 없이 사용하는 연습 모드는 각 기기에 저장합니다. 실제 주식 주문이나 현금 투자를 제공하지 않습니다.

## 테스트 APK

`v1.0.2-preview.1`은 주식왕 전용 API 주소를 적용한 ARM64 테스트 버전입니다. MTS 형태의 주문창과 Android 하단 내비게이션 안전 영역 개선을 포함하며 기존 계정·자산을 그대로 사용합니다. Android 7.0 이상이 필요합니다. JS 번들을 포함하므로 Metro를 실행하지 않아도 됩니다.

APK는 기존 개발 키로 서명했으며 정식 배포용이 아닙니다. 기존 앱과 서명 키가 다르면 업데이트 설치가 제한됩니다. APK 설치 후 기존 계정으로 로그인하거나 회원가입과 메일 인증을 진행하세요. 다운로드 파일 검증에는 Release에 첨부한 `SHA256SUMS`를 사용합니다.

2026-10-12 주문 UI 개선: 참고 호가 터치로 지정가 입력, 매수·매도 전환, 가격·수량 조절, 하단 주문 금액·접수 버튼 고정을 지원합니다. 탭바와 주문·차트·출석 등 팝업에 시스템 안전 영역을 적용했습니다. 브라우저 연습 거래를 확인했으며 이번 수정의 Android 실기기 검증은 사용자 기기에서 이어서 확인해야 합니다.

이 저장소에는 공개 소개 페이지·웹 앱 빌드와 APK를 배포합니다. 서버 키·DB 설정·Android 정식 서명 키는 포함하지 않습니다. 웹의 Android 광고 재생·APK 설치 기능은 지원하지 않습니다. 테스트 버전은 prerelease로 게시하며, 정식 APK 자동 업데이트 채널과 구분합니다.
