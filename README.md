# 주식왕 다운로드

[웹에서 시작하기](https://skim72.github.io/stockking-downloads/app/) · [주식왕 소개·다운로드 페이지](https://skim72.github.io/stockking-downloads/) · [APK와 변경 내역](https://github.com/SKIM72/stockking-downloads/releases)

주식왕은 가상 자산으로 시세·주문·기업 투자·은행·시즌 순위를 즐기는 웹·Android 주식 게임입니다. 같은 계정으로 로그인하면 서버에 저장된 잔액·보유 주식·주문을 함께 이용합니다. 로그인 없이 사용하는 연습 모드는 각 기기에 저장합니다. 실제 주식 주문이나 현금 투자를 제공하지 않습니다.

## 테스트 APK

`v1.5.0-preview.1`은 앱 복귀 때 업데이트 확인 화면이 번쩍이는 동작을 없애고, 새 버전이 있으면 설치 전까지 플레이를 제한합니다. 홈의 출석 카드를 자산 바로 아래로 옮겼으며 출석 보상은 가상경제 계좌에 현금으로 바로 지급합니다. 별도 포인트 교환은 없고, 기존 포인트 기록은 보존합니다. 프로필·Outline 아이콘·반투명 알약 메뉴·다크/라이트 테마·기업 경영·시즌 결산도 함께 제공합니다. Android 7.0 이상 ARM64이며 Metro가 필요하지 않습니다.

‘실제 시세 모의투자’에서는 실제 국내 종목 코드와 별도의 1,000만 원 주간 모의 계좌를 준비할 수 있습니다. 시세 제공사가 아직 연결되지 않아 현재 가격·주문·체결·경쟁 순위는 활성화하지 않습니다. 가상경제 출석·기업·부동산·대출·현금 보상은 이 모의 계좌에 반영하지 않습니다. 초기 주문 모델은 계좌별 전량 체결, 수수료·세금 0원이며 실제 운용 전 제공사·거래 상태·캘린더·거래 비용을 연결해야 합니다.

현실 60분 = 게임 하루, 게임 09:00~15:30 개장, 현실 7일 시즌이 기본 규칙입니다. 다음 시즌 현금 보상은 기본 시작 자금의 최대 5%이며 관리자 페이지에서 조정할 수 있습니다. 웹과 Android는 같은 API·Supabase 인증·DB를 사용합니다.

APK는 기존 개발 키로 서명했으며 정식 배포용이 아닙니다. 기존 앱과 서명 키가 다르면 업데이트 설치가 제한됩니다. APK 설치 후 기존 계정으로 로그인하거나 회원가입과 메일 인증을 진행하세요. 다운로드 파일 검증에는 Release에 첨부한 `SHA256SUMS`를 사용합니다.

검증: 147개 테스트·전체 타입 검사, 격리 PostgreSQL/API의 출석 현금 중복 방지·연속/월간 보상·기존 포인트 보존과 분리 모의 계좌·후속 호가·취소 환불·주간 마감·API 재시작·직접 DB 접근 제한을 확인했습니다. Safari 390px에서 홈 출석→현금 지급→완료 표시, 분리 모의 계좌 준비와 필수 업데이트 지속성을 확인했습니다. APK 버전·기존 서명·해시와 Linux AMD64 이미지 실행을 검사했으며 Android 실기기의 새 화면·업데이트 설치는 별도 확인이 필요합니다.

이 저장소에는 공개 소개 페이지·웹 앱 빌드와 APK를 배포합니다. 서버 키·DB 설정·Android 정식 서명 키는 포함하지 않습니다. 웹의 Android 광고 재생·APK 설치 기능은 지원하지 않습니다. 현재 설치 사용자와 같은 서명을 사용하는 Preview 업데이트 채널에서 새 APK를 내려받아 설치할 수 있습니다. 필수 버전 미만은 게임 플레이가 제한되며 웹은 새로고침으로 갱신합니다. Android의 설치 확인은 사용자가 직접 진행합니다. 정식 서명 채널과는 구분합니다.
